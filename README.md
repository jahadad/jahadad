# Jose Agustin Hadad

Support and customer success operations, based in Córdoba, Argentina. Eight years in SaaS, the last five running support and CS ops across 20+ brands at a fully remote company.

Most of what I build is for operations: automations that take repetitive work off a team, trackers that show where every team stands, and small tools that put a process where a person used to chase it. I trained as a full-stack developer, so when the work needs a tool I usually build it myself.

Public here:

- **[world-cup-2026-pool](https://github.com/jahadad/world-cup-2026-pool)**: a World Cup prediction pool (Django, Postgres, Railway) that ran in production during the 2026 tournament, with private leagues and results loading automatically from two sources.
- **[preobra-cordoba](https://github.com/jahadad/preobra-cordoba)**: a pre-construction feasibility tool for Córdoba built on the province's open geodata (Laravel, MapLibre): zoning map, buildable-area calculator and unit-mix simulator.
